# Souvenir

Notion 플러그인에 연결해 여행 플래너를 만들고, 새 여행을 계획하고, 기존 일정을 수정하는 여행 도우미 스킬이에요.

## 시작하기

1. Codex에서 이 저장소 폴더를 열어요.
2. Notion 플러그인을 연결하고, 사용할 페이지에 접근할 수 있는지 확인해요.
3. 채팅에 `$souvenir`를 입력하면 세 가지 작업이 나와요. 번호나 작업 이름을 입력해 시작할 수 있어요.

| 선택지 | 하는 일 |
|---|---|
| 1. 여행 플래너 만들기 | 기본 Notion 양식을 만들거나 기존 템플릿을 사용해요. |
| 2. 새 여행 계획 | 목적지와 날짜 또는 기간을 받아 여행 일정을 만들어요. |
| 3. 기존 일정 수정 | 바뀌는 항목을 먼저 보여주고, 확인한 부분만 반영해요. |

템플릿이나 저장 위치를 이미 정했다면 Notion 페이지 링크를 함께 알려주세요. 템플릿이 없어도 기본 양식으로 여행을 시작할 수 있어요.

예시

> $souvenir 새 여행 계획. 후쿠오카 3박 4일이고 예산과 숙소는 아직 미정이야.

스킬의 작업 규칙은 [SKILL.md](.agents/skills/souvenir/SKILL.md)에 있어요. 첫 버전의 시작 메뉴는 채팅에서 번호로 선택하는 방식이에요.
