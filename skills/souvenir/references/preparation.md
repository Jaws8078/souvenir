## 준비할 일과 준비물

`준비할 일`은 실행할 작업 한 건당 한 행이다. 여행 전·출발 당일·여행 중·귀국 전·귀국 후로 나누고 담당 여행자 한 명·기한·중요도·상태를 관리한다. 시점별 표·진행 보드·기한 달력·기한 확인·출발 당일·귀국 전후·여권/입국 확인·제외 포함 뷰를 사용한다. 기한이 없어도 작성한다. 완료·제외 항목에는 기한 지남 경고를 표시하지 않는다. 실제 예약은 기존 예약 관리에 연결하며 할 일 완료가 예약 상태를 바꾸지는 않는다.

여권·입국 요건은 목적지·국적·경유·여행일에 맞는 공식 근거, 확인일·결과·확인 상태로 기록한다. 기본 체크리스트가 있다는 이유로 현재 입국 요건을 확인했다고 말하지 않는다. 실제 요건을 조사할 때는 필요한 조건과 공식 자료를 확인하고, 미정인 조건은 확인 필요로 남긴다. 보험·통신·환전/카드·집/반려동물·업무도 실행할 일로 기록하되 사용자의 실제 가입·소유·반려동물·업무 상황을 추정하지 않는다.

`준비물`은 기존 DB를 확장한다. 공용/개인·분류·필수 체크, 담당 여행자·수량/챙긴 수량·구매 상태/링크·수납 위치, 계절·날씨/활동 조건을 기록한다. 필수/미완료·구매/확인·공용·담당자별·계절/날씨/활동·귀국 소지품·제외 포함 뷰를 제공한다. 기존 담당자 텍스트는 보존하고 진행률은 여행자 담당 관계로 집계한다. 구매 완료, 수량 확인, 준비 완료 상태, 귀국 소지품 확인은 별개다. 수량을 채웠다고 상태를 자동 완료하지 않으며, 수납 위치 선택이 항공사 반입 허용을 검증한 표시도 아니다. 귀국 확인 대상만 골라 귀국 전 다시 체크하고 확인일을 남긴다.

진행률은 할 일과 준비물을 각각 계산한다. 완료/준비 완료만 분자에 포함하고 제외는 분모에서도 뺀다. 미배정 항목도 전체 수에 포함하며 담당자별 집계는 대표 담당 한 명을 기준으로 한다. 항목이 0개면 등록된 항목 없음으로 표시하고 100% 완료로 추정하지 않는다. 이 진행률은 Notion에서 상태 변경을 반영하는 검증된 수식/롤업이며, 별도 검토 스냅샷인 금전 정산과 혼동하지 않는다. 여행 카드에는 자동 진행을 보정하는 `직접 완료`·`자동 제외` 체크박스를 묶음별로 둔다. 자동 완료 결과는 수식으로 표시하고, 사용자가 직접 완료를 켜거나 자동 완료를 제외할 수 있게 한다. 수식 속성 자체를 사용자가 편집 가능한 체크박스로 가장하지 않는다.

기본 템플릿에는 시작용 할 일 15개·품목 8개가 `구분=기본`으로 있다. 새 여행에서는 기본 항목의 이름·분류·시점·선택용 조건만 복사하고 새 여행에 연결한다. 할 일은 시작 전, 준비물은 미정으로 시작하며 예전 여행의 완료·구매·귀국 체크·기한·실제 확인 결과·예약 연결·담당자·챙긴 수량을 그대로 가져오지 않는다. 수량·필수 여부는 사용자가 알려준 선호와 여행 조건에 맞추고 미정인 것은 비워둔다. 예시는 복사하지 않고 원본 템플릿의 상태도 바꾸지 않는다. 새 여행에서는 준비 현황의 `여행 키` 필터와 할 일·준비물·담당자별 뷰를 해당 여행에 맞춘다.
