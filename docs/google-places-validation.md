# Google Places 데모 키 검증 기록

검증일: 2026-11-18 (Asia/Seoul)

로컬 `.env`의 데모 키를 실행 프로세스의 환경변수로 주입해 Places API (New)를 직접 호출했다. 키·페이지 토큰·원본 후보 응답은 이 문서나 저장소에 기록하지 않았다. Notion 데이터는 생성·수정하지 않았다.

## 실행 결과

| 검증 | 방식 | 결과 |
| --- | --- | --- |
| 장소 검색·요약 필드 | 후쿠오카 카페 실검색 | 비어 있지 않은 후보, 장소 ID, HTTPS 지도 링크 확인 |

| 비밀 관리 | 추적 파일 여부·결과 문자열 확인 | `.env` Git 제외·미추적, 테스트 결과에 키 없음 |

실 API 테스트: **11개 통과**, 6.285초. 전체 회귀 테스트: **174개 중 162개 통과·선택 실행 12개 건너뜀**, 2.740초. 시간은 해당 실행의 전체 소요 시간이며, API 개별 응답 지연이나 서비스 성능 보장 수치가 아니다. 매니페스트 `validate`와 읽기 전용 `plan`도 통과했다.

## 재현 후 수정한 문제

1. **혼합 언어 주소의 목적지 오판**: 한국어 검색에서도 주소가 `Fukuoka`나 `福岡`로 반환된다. 기존 한글 문자열 비교와 강제 일치 근거 때문에 정상 후보가 불일치로 처리됐다. Unicode 장소 토큰과 주요 도시 표기 별칭을 적용하고, 주소를 강제 확인 근거로 만드는 처리를 제거했다. 별칭이 없는 지역은 확인 필요로 남는다.
2. **마지막 페이지 전체 수 오류**: 마지막 묶음의 개수만 전체 수로 표시했다. 누적 표시 건수로 집계하고 기존 페이지 번호·시작/종료 순위도 함께 맞췄다. 여기서 전체 수는 이 검색에서 제공자가 반환한 누계이며, 조건에 맞는 모든 실제 장소 수는 아니다.
3. **인증 오류 분류 누락**: 잘못된 키가 HTTP 400과 `API_KEY_INVALID`로 반환돼 일반 입력 오류로 분류됐다. 구조화된 원인을 읽어 `GOOGLE_AUTH`로 처리한다.
4. **다음 페이지 상태 검증 보강**: 목적지와 페이지 번호를 세션에 묶고, 이전 페이지의 장소 ID로 페이지 간 중복을 제거한다. 새 세션 계약이 없는 이전 토큰은 새 검색으로 시작해야 한다.

동일 문제가 CI에서 다시 생기지 않도록 주소 언어·누계·페이지 간 중복·세션 변경·인증 오류의 오프라인 회귀 테스트도 추가했다.

## 아직 통과했다고 말할 수 없는 항목

- **Notion 종단 간 저장·확인 존·모바일 표시**: 연결 상태만 읽었다. 실제 테스트 여행/복제본의 저장·관계·필터·수식·화면은 별도 검증해야 한다. 현재 워크스페이스는 `ys_kim님의 워크스페이스`다.
- **위치 반경·실제 거리순 검증**: `locationBias`는 선호 위치이며 엄격한 반경 필터가 아니다. 좌표별 거리와 이동 시간 계산, strict type filtering은 이번 테스트에 포함하지 않았다.
- **분위기·1인 예산 정확 필터**: 검색어는 전달되지만 조용함이나 정확한 1,500엔 이하 지출을 보장하는 구조화 검증은 없다. 가격·분위기는 추가 출처 확인이 필요하다.
- **429·5xx·타임아웃·잘못된 JSON**: 오프라인 오류 주입 테스트로 검증했다. 실서버의 한도 소진·장애를 일부러 일으키지는 않았다.
- **사진·리뷰**: 데모 키는 사용자 사진·리뷰를 지원하지 않는다. 현재 검색도 사진·리뷰 본문을 요청하지 않으므로 자동 사진 등록 검증과 별개다.
- **호스트 웹 검색·CUA 복제·다른 운영체제**: 키 없는 실행기의 요청 패킷 전환까지 확인했으며, 각 호스트의 실제 검색/화면 자동화를 모두 실행한 것은 아니다.
- **사용자별 키 없는 서버 운영**: 중계 서버·사용자 인증·쿼터·공개 운영 키 전환은 구현/검증 범위 밖이다.
- **`.env` 자동 로딩**: 실행기는 `.env`를 자동으로 읽지 않는다. 이번 테스트에서는 실행 시 환경변수로 주입했다. 새 프로세스에서도 API를 사용하려면 호스트가 이 주입을 수행해야 한다.

## 다시 실행하기

로컬 개발자 검증용이다. 일반 CI에서는 실 API 요청 없이 선택 테스트를 건너뛴다.

```bash
set -a
source .env
set +a
SOUVENIR_LIVE_GOOGLE_TEST=1 python3 -m unittest discover \
  -s skills/souvenir/tests -p 'test_google_places_live.py' -v
```
